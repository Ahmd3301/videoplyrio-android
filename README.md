# VideoPlyrIO Android

Professional Android video player combining:
- **Plyr.io UI** — pixel-perfect visual clone
- **ExoPlayer (Media3)** — native playback engine
- **Jetpack Compose** — modern UI framework
- **Telegram-style PiP** — floating overlay window

## Features
- HLS, DASH, MP4 and all major video formats
- Stream extraction from websites (WebView-based)
- Glass blur controls overlay
- Animated playlist
- Speed & quality controls
- Arabic + English (RTL support)
- Overlay PiP (drag anywhere on screen)
